goedam 개인정보처리방침

시행일: 2026년 11월 16일

1. 이 도구가 하는 일

goedam은 개발자 본인의 유튜브 채널에 영상을 올리는 개인용 도구입니다. 개발자 본인의 구글 계정으로만 사용하며, 다른 사람의 구글 계정에 접근하지 않습니다.

2. 접근하는 정보

이 도구는 YouTube API 서비스를 사용합니다. 개발자 본인이 허용한 범위 안에서 다음 정보에만 접근합니다.

  • 연결된 유튜브 채널의 이름과 채널 ID(올릴 채널이 맞는지 확인하는 데 씁니다)
  • 올리는 영상 파일과 그 제목, 설명, 공개 설정

3. 보관

구글이 발급한 인증 토큰은 개발자의 컴퓨터에만 보관합니다. 이 도구는 따로 서버를 두지 않으며, 위 정보를 다른 곳에 모으거나 보관하지 않습니다.

4. 제3자 제공

이 도구는 위 정보를 다른 사람이나 회사에 제공하거나 판매하지 않습니다. 광고에 쓰지 않습니다.

5. 사용 중지와 삭제

구글 계정의 보안 설정에 있는 서드 파티 앱 액세스 목록에서 이 도구의 액세스 권한을 언제든지 삭제할 수 있습니다(https://myaccount.google.com/permissions). 삭제하면 이 도구는 더 이상 채널에 접근할 수 없습니다.

6. 적용되는 약관

이 도구는 YouTube API 서비스를 사용하므로 YouTube 서비스 약관이 적용되며, 구글의 정보 처리에는 Google 개인정보처리방침이 적용됩니다.
